# SACH-METER--VIRAL-CLAIM-RADAR
Sach Meter - Viral Claim Radar is an AI-powered fact-check copilot that analyzes posts, images, and text, classifying them as True, Fake, or Uncertain with confidence scores and source-backed insights.
#  Viral Claim Radar  
### Real-Time Fact-Check Copilot for Social Media

In a world where misinformation spreads faster than facts, Viral Claim Radar helps users instantly verify claims using AI.

---

##  Features
-  Upload text, image, or claim
-  AI-powered claim extraction
- Classification: True / Fake / Uncertain
-  Confidence score (%)
-  Source-backed explanations
-  Real-time results
-  Clean single column dashboard UI

---

##  What Makes It Different
Unlike traditional fact-checkers, this system:
- Handles uncertainty explicitly
- Shows confidence levels
- Provides transparent source-backed reasoning

---

##  Tech Stack
- Frontend: Streamlit, React 
- Backend: FastAPI  
- AI/NLP: Python, Transformers / Scikit-learn  
- Data: Fact-check datasets
